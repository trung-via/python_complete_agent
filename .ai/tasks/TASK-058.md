## Core Requirement 2 — Operational Proof Receipt

Create `src/aios_bridge/paid_api_operational_proof.py` with a frozen strict receipt type and pure/offline builder described by the blueprint.

The verifier accepts exact:

```text
PaidApiBrainEscapeResult
PaidApiGrant
AtomicPaidApiGrantStore
ModelRequest
```

and must verify ALL of the following before returning a receipt:

### Paid authority / dispatch

```text
paid_candidate_selected == True
grant_consumed == True
effective allow_paid_api == True
dispatch status == SELECTED
actor_kind == BRAIN
selected_actor_id == grant.brain_id
```

### Durable grant state

```text
ACTIVE == None
CONSUMED == exact grant
grant fingerprint exact
```

Verifier is read-only; it must not consume/reactivate/mutate grant state.

### Original local evidence

```text
exact ProviderInputCountEvidence
provider/model == grant
request fingerprint == fingerprint_model_request(model_request)
token_count_is_exact == True
local count <= request max_input <= grant max_input
```

### Successful Gateway result

Require exact successful response and correlations:

```text
response.status == SUCCESS
request_id/task_id/provider/model exact
output_type exactly matches model_request.operation
provider_request_id non-empty
input_tokens exact non-negative int
output_tokens exact non-negative int
output_tokens <= request max_output <= grant max_output
```

### Critical token equality

```text
LOCAL_PRECALL_INPUT
  == ModelResponse.input_tokens
  == UsageRecord.provider_input_tokens
```

No tolerance or adjustment. Mismatch = proof failure.

### Usage ledger

```text
ledger_persisted == True
ledger_error_code == None
UsageRecord exact request/task/provider/model/status/provider_request_id correlation
UsageRecord provider input/output tokens == ModelResponse input/output tokens
```

### Receipt

Receipt contains bounded metadata only, including:

```text
schema_version
task_id
grant_id
grant_fingerprint
brain_id
provider_id
model_id
request_id
model_request_fingerprint
authorized_artifact_path
authorized_artifact_blob_sha
counter_id
local_pre_call_input_tokens
provider_reported_input_tokens
provider_reported_output_tokens
provider_request_id
response_status
ledger_persisted
grant_consumed
input_token_match
response_content_sha256
```

No prompt/context/output plaintext, API key, headers, cookies, raw response body, tokenizer/template bytes, or credentials.

Provide deterministic canonical JSON and deterministic SHA-256 receipt fingerprint.
