## Objective

Replace the implicit 30-second magic timeout in the M11.3C live paid-proof command with a required, explicit, bounded provider timeout envelope.

The corrective design is:

```text

REQUIRED: YES

MAX_SECONDS: 180
RECOMMENDED_NEXT_LIVE_PROOF_SECONDS: 120
DEFAULT_IF_OMITTED: NONE
```

The next live proof will explicitly use `120` seconds after TASK-063 PASS + Human merge + a fresh Human paid grant. TASK-063 RUN/FIX itself remains strictly no-spend.

```text

  --subscription-capacity-fingerprint <exact 64-hex>
```

The parameter is required. Omission must fail at CLI parsing before runtime authority or credential logic. Values outside the inclusive range `60..180` must fail closed before credential value access, grant consumption, provider construction, or provider invocation.

No alternate environment-variable timeout, hidden default, config-file override, floating-point value, or unbounded value is allowed.
