## Exact Validation Rules

### Schema

`schema_version` must equal `"1"` exactly.

### grant_id

- exact `str`, non-empty;
- no leading/trailing whitespace;
- max length 96;
- conservative identifier regex:

```text
^[a-z0-9]+(?:[a-z0-9_.:-]*[a-z0-9])?$
```

### task_id

Exact case-sensitive:

```text
^TASK-[0-9]+$
```

### actor_kind

Must parse to `DispatchActorKind.BRAIN` exactly.

`EXECUTOR` MUST be rejected.

### brain_id / provider_id / model_id

Each:
- exact non-empty `str`;
- no leading/trailing whitespace;
- bounded by its public maximum;
- no CR/LF/NUL;

`brain_id` and `provider_id` additionally use conservative actor/provider identifier regex:

```text
^[A-Za-z0-9][A-Za-z0-9_.:-]*$
```

`model_id` may contain ordinary printable model-name characters but MUST reject control characters and whitespace padding.

### brain_operation

Must parse to existing `BrainOperation` enum.

Do not invent new operations.

### authorized_artifact_path

Canonical repository-relative path only:
- exact non-empty `str`;
- slash-normalized `/` form only;
- no backslash;
- no absolute path;
- no drive prefix / colon;
- no empty, `.` or `..` path component;
- no NUL/CR/LF;
- MUST start with `.ai/`.

M11.1 does not touch filesystem and does not prove existence.

### authorized_artifact_blob_sha

Exact lowercase 40-hex Git blob SHA:

```text
^[0-9a-f]{40}$
```

### max_input_tokens

Exact `int`, excluding bool:

```text
1 <= value <= MAX_PAID_API_INPUT_TOKENS
```

### max_output_tokens

Exact `int`, excluding bool:

```text
1 <= value <= MAX_PAID_API_OUTPUT_TOKENS
```

### max_calls

Exact integer `1`, excluding bool.

### expires_at_epoch_seconds

Exact positive integer, excluding bool.

M11.1 performs no wall-clock lookup; expiry-at-now checking belongs to M11.2 runtime binding.

### workspace_id

Exact lowercase 64-hex SHA-256.

### grant_fingerprint

Semantic fingerprint is SHA-256 over canonical JSON of every field above EXCEPT `grant_fingerprint`.

Canonical JSON rules:

```python
json.dumps(value, sort_keys=True, separators=(",", ":"), ensure_ascii=False)
```

Constructor behavior:
- if `grant_fingerprint is None`, compute and freeze the canonical fingerprint;
- if provided, require exact lowercase 64-hex AND exact equality to recomputation;
- mismatch fails closed.

## Budget Validator

Implement pure function:

```python
validate_paid_api_grant_budget(
    grant: PaidApiGrant,
    *,
    input_tokens: int,
    output_tokens: int,
) -> None
```

Rules:
- exact ints excluding bool;
- values must be non-negative;
- `input_tokens <= grant.max_input_tokens`;
- `output_tokens <= grant.max_output_tokens`;
- over-budget fails closed.

Zero is valid for this validator because it validates a measured/requested amount, while grant maxima themselves must be positive.

No pricing/currency logic.
