## 4. AtomicRuntimeCapacityStore

```python
class AtomicRuntimeCapacityStore:
    def __init__(self, root: Path): ...
    def record_path(self, actor_kind, actor_id) -> Path: ...
    def write(self, record: RuntimeCapacityRecord) -> None: ...
    def load(self, actor_kind, actor_id) -> RuntimeCapacityRecord | None: ...
    def list_records(self, actor_kind=None, actor_id=None) -> tuple[RuntimeCapacityRecord, ...]: ...
```

Path:

```text
<root>/<ACTOR_KIND>/<actor_id>.json
```

Atomic write algorithm:
1. validate path components before filesystem access;
2. mkdir parent;
3. canonical bytes = `record.to_canonical_json().encode("utf-8") + b"\n"`;
4. temp sibling using unpredictable suffix;
5. open `xb`;
6. write, flush, `os.fsync`;
7. `os.replace(temp, final)`;
8. best-effort directory fsync where supported;
9. clean temp on error;
10. read-back and fingerprint equality required; otherwise raise.

Load:
- exact path only, no scanning fallback;
- missing => None;
- invalid UTF-8/JSON/schema/fingerprint => raise;
- max byte bound before parse.

List:
- deterministic actor-kind then actor-id order;
- only exact `.json` files one level under actor-kind directory;
- malformed discovered record => fail closed, not skip.
