### Verifier order

Implement exact fail-closed order:

1. Resolve repository root and require execution from that exact root.
2. Require current branch exactly `ai/task-036`.
3. Require current `git rev-parse HEAD` exactly `BASELINE_SHA`; no intermediate source/replacement commit is allowed.
4. Load exact ACTIVE authorization for task 36. Missing/non-ACTIVE fails.
5. Require:
   - task_id == TASK-036;
   - action == RUN;
   - branch == ai/task-036;
   - executor_id == antigravity.
6. Reconstruct exact current replacement lease from authorization.
7. `get_lease_store().require_active(replacement_lease)`.
8. Call existing `validate_active_hot_handoff_provenance(36, auth, replacement_lease)` and require non-null metadata.
9. Require metadata actors exactly codex -> antigravity and distinct.
10. Load the exact checkpoint only with:

```python
load_persisted_hot_handoff_checkpoint(36, metadata["checkpoint_fingerprint"])
```

11. Require checkpoint:
   - task_id == TASK-036;
   - target_branch == ai/task-036;
   - head_sha == BASELINE_SHA;
   - workspace_id == current workspace ID;
   - source_executor_id == codex;
   - source lease/execution fingerprints equal metadata source fields;
   - allowed_paths == `(SOURCE_PATH,)`.
12. Require checkpoint manifests contain exactly one dirty payload total and it is SOURCE_PATH.
13. Require SOURCE_PATH is in the checkpoint untracked manifest (not tracked), because it did not exist at baseline.
14. Read current SOURCE_PATH without following symlinks; require regular UTF-8 text file; compute SHA-256 + size and require exact equality with checkpoint manifest entry.
15. Require current SOURCE_PATH exact content equals the Stage-A canonical source payload in this blueprint.
16. Require REPLACEMENT_PATH absent from both checkpoint manifests.
17. Read current REPLACEMENT_PATH without following symlinks; require regular UTF-8 text file.
18. Require its exact content matches the replacement marker format and contains the exact checkpoint fingerprint from active metadata.
19. Compute replacement SHA-256 + size.
20. Build deterministic semantic proof object.
21. Compute `proof_fingerprint = sha256(canonical_json(semantic_proof))` with JSON `sort_keys=True`, separators `(',', ':')`, UTF-8, `ensure_ascii=False`.
22. Write `{**semantic_proof, "proof_fingerprint": ...}` to OUTPUT_PATH as canonical JSON plus one newline. Use atomic temp-file replace if practical.
23. Read it back and verify exact bytes/fingerprint before reporting PASS.
