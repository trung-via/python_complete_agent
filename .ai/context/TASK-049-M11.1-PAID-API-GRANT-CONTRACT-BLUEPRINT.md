## Exact Validation Rules

### schema_version

Must equal `PAID_API_GRANT_SCHEMA_VERSION` exactly.

### grant_id

- exact `str`, non-empty;
- no leading/trailing whitespace;
- maximum `MAX_PAID_API_GRANT_ID_LENGTH`;
- exact conservative regex:

```text
^[a-z0-9]+(?:[a-z0-9_.:-]*[a-z0-9])?$
```

### task_id

Exact case-sensitive canonical form:

```text
^TASK-[0-9]+$
```

Reject whitespace padding and non-string values. Do not normalize or case-fold.

### actor_kind

Accept/parse only an existing `DispatchActorKind` value and require:

```text
DispatchActorKind.BRAIN
```

`DispatchActorKind.EXECUTOR` MUST fail closed.

No new actor kinds.

### brain_id / provider_id / model_id

Each:
- exact non-empty `str`;
- no leading/trailing whitespace;
- no NUL/CR/LF/control-character acceptance;
- bounded by the corresponding public maximum.

`brain_id` and `provider_id` additionally require:

```text
^[A-Za-z0-9][A-Za-z0-9_.:-]*$
```

`model_id` may contain ordinary printable model-name characters but MUST reject control characters and whitespace padding.

### brain_operation

Accept/parse only existing `BrainOperation` values from `continuity.state`.

Do not invent, alias, infer, or case-fold operations.

### authorized_artifact_path

Canonical repository-relative path only:
- exact non-empty `str`;
- slash-normalized `/` form only;
- no backslash;
- no absolute path;
- no drive prefix / colon;
- no empty component;
- no `.` or `..` component;
- no NUL/CR/LF;
- MUST start with `.ai/`.

M11.1 performs no filesystem lookup and does not prove existence.

### authorized_artifact_blob_sha

Exact lowercase 40-hex Git blob SHA:

```text
^[0-9a-f]{40}$
```

### max_input_tokens

Exact `int`, explicitly excluding `bool`:

```text
1 <= value <= MAX_PAID_API_INPUT_TOKENS
```

### max_output_tokens

Exact `int`, explicitly excluding `bool`:

```text
1 <= value <= MAX_PAID_API_OUTPUT_TOKENS
```

### max_calls

Exact integer `1`, explicitly excluding bool.

### expires_at_epoch_seconds

Exact positive integer, excluding bool.

M11.1 MUST NOT perform a wall-clock lookup. Expiry-at-now validation belongs to M11.2 runtime binding.

### workspace_id

Exact lowercase 64-hex SHA-256 string.

### grant_fingerprint

Semantic fingerprint is SHA-256 over canonical JSON of every field above EXCEPT `grant_fingerprint`.

Canonical JSON is exactly:

```python
json.dumps(value, sort_keys=True, separators=(",", ":"), ensure_ascii=False)
```

Constructor behavior:
- if `grant_fingerprint is None`, compute the canonical fingerprint and freeze/store it;
- if provided, require exact lowercase 64-hex and exact equality with recomputation;
- mismatch fails closed.

Enum values in semantic serialization MUST serialize to their stable string `.value`, not Python reprs.

## Required Methods

Implement:

```python
semantic_dict() -> dict[str, Any]
to_dict() -> dict[str, Any]
to_canonical_json() -> str
fingerprint() -> str
@classmethod from_dict(cls, data: Any) -> PaidApiGrant
@classmethod from_json(cls, value: str | bytes) -> PaidApiGrant
```

`semantic_dict()` excludes only `grant_fingerprint` and emits JSON-serializable stable values.

`to_dict()` includes `grant_fingerprint`.

`to_canonical_json()` serializes `to_dict()` using the exact canonical JSON rules above.

`fingerprint()` recomputes the semantic fingerprint from `semantic_dict()`; it MUST NOT simply trust the stored fingerprint field.

`from_dict` MUST require exact field set: no missing fields and no extra fields.

`from_json`:
- accepts exact `str` or `bytes` only;
- bytes must decode as strict UTF-8;
- malformed JSON fails closed;
- JSON root must be object;
- no permissive coercion.

## Budget Validator

```python

    grant: PaidApiGrant,
    *,
```

Rules:
- exact ints excluding bool;
- requested/measured values must be non-negative;
- `input_tokens <= grant.max_input_tokens`;

Zero is valid for this validator because it validates a requested/measured amount; grant maxima themselves remain strictly positive.
