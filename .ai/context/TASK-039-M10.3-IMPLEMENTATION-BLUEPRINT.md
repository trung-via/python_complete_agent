## 7. Safe Exact External Receipt Reader

Implement a small helper with explicit exact-path semantics, for example:

```python

```

Required behavior:
- exact path is `runtime_root / EXTERNAL_RECEIPT_REL` only;
- reject missing path;
- reject symlink leaf;
- reject symlink parent components under runtime root;
- require physical resolved confinement under runtime root / `dispatch/proofs/TASK-039`;
- require regular file;
- read at most `MAX_RECEIPT_BYTES + 1`;
- reject empty/oversized/NUL;

- return raw bytes, decoded normalized text, SHA-256, `st_mtime_ns`, exact path.

Do not search alternate directories, history, `*.txt`, latest files, or fallback receipts.

The committed receipt copy must preserve exact raw bytes read from this external file.
