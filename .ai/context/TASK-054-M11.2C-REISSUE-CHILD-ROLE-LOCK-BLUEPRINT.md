## Locked Execution Order

Before constructing any request with `allow_paid_api=True`:

1. Require exact input types / fail closed.
2. Require `base_dispatch_request.allow_paid_api is False`.
3. Require exactly one candidate with `capacity_class == PAID_API`.
4. Require that candidate brain ID exactly equals `grant.brain_id`.
5. `grant_store.require_active(grant, now_epoch_seconds=...)`.
6. Require exact task/workspace/brain/provider/model/continuity-operation/artifact binding.
7. Require gateway provider ID/model identity match grant.
8. Require exact continuity -> External Brain operation mapping.
9. Require `model_request.context == context_build.selected`.
10. Require exact authorized artifact selected-context content/blob proof.
11. Require exact token-counter evidence and grant budget bounds.
12. Only then build a fresh immutable `BrainDispatchRequest` identical to base except `allow_paid_api=True`.
13. Call existing pure `dispatch_brain()`.
14. If subscription/WAIT/no-compatible outcome: do NOT consume; do NOT call gateway; return evidence.
15. If paid selected: selected actor must equal grant brain.
16. `grant_store.consume(grant, now_epoch_seconds=...)` MUST succeed durably.
17. Only after step 16: `await gateway.invoke(model_request, context_build=context_build)` exactly once.
18. Return result. Never retry/failover/reactivate.

## Exact Artifact-In-Context Proof

Require exact:

```text

authorized_artifact.blob_sha == grant.authorized_artifact_blob_sha
```

Then exactly one `ContextItem` in `context_build.selected` must have `path == grant.authorized_artifact_path`.

Compute the Git SHA-1 blob object ID from exact UTF-8 content:

```python
payload = content.encode("utf-8")
blob_sha = hashlib.sha1(
    b"blob " + str(len(payload)).encode("ascii") + b"\0" + payload
).hexdigest()
```

Require `blob_sha == grant.authorized_artifact_blob_sha`.

No Git subprocess and no filesystem fallback.

```text
paid_candidate_selected = false

gateway_result = None
```

```text

paid_candidate_selected = true
grant_consumed = true
```

## Failure / Replay / Concurrency

```text
consume failure -> gateway calls 0
consume success + gateway exception -> grant remains CONSUMED, no retry
provider failure response -> grant remains CONSUMED, no retry
ledger failure -> grant remains CONSUMED, no retry/regrant
sequential replay -> fails at ACTIVE/consume gate before gateway
concurrent same-grant race -> at most one consume winner and at most one gateway invocation
```

Never restore ACTIVE after a consume.
